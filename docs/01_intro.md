# Введение

Это моя первая автоматизированная документация.

## Цель
- Изучить инструменты автоматизации.
- Научиться хранить документацию в системе контроля версий.
- Научиться оформлять документы с помощью Markdown.
- Познакомиться с PlantUML и OpenAPI.

**Важно:** документация — это часть продукта и должна сопровождаться так же внимательно, как программный код.

## Используемые инструменты
- **GitHub** — хранение файлов и история изменений.
- **Markdown** — удобное текстовое оформление.
- **PlantUML** — создание схем из текстового описания.
- **OpenAPI / Swagger Editor** — описание интерфейса API.
- **GitHub Pages** — публикация сайта документации.
