# Отчёт о работе

В ходе практической работы я изучил(а) основы автоматизации разработки технической документации.

Я создал(а) репозиторий GitHub, добавил(а) документы в формате Markdown, познакомился(ась) с историей изменений и подготовил(а) сайт с помощью GitHub Pages.

Также я подготовил(а) текстовую схему процесса в PlantUML и описание учебного API в формате OpenAPI.

**Мой сайт:** ВСТАВЬТЕ_СЮДА_ССЫЛКУ_НА_GITHUB_PAGES

## Вывод
Использование GitHub помогает хранить документацию в одном месте, отслеживать изменения и возвращаться к предыдущим версиям. Markdown упрощает оформление текста, PlantUML позволяет изменять схемы через текст, а GitHub Pages помогает публиковать документацию как сайт.
