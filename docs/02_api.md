# Описание API

## Назначение
API демонстрирует условную функцию входа пользователя в систему.

## Метод и адрес
`POST /login`

## Входные данные
Запрос содержит JSON-объект с двумя строковыми полями:
- `login` — имя пользователя;
- `password` — пароль.

## Успешный ответ
Код `200` означает, что запрос обработан успешно.

> Это учебный пример. Он не подключён к реальной системе авторизации и не проверяет учётные данные.
